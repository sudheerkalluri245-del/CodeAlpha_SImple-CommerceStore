# CodeAlpha Simple E-Commerce Store

## Project Overview

This project is a Simple E-Commerce Store developed as part of the CodeAlpha Full Stack Development Internship.

The application allows users to browse products, view product details, register and log in, add products to a shopping cart, and place orders.

## Technologies Used

### Frontend

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

### Backend

* Django (Python)

### Database

* SQLite

## How to Run

1. Create Virtual Environment

python -m venv venv

2. Activate Environment

Linux:
source venv/bin/activate

Windows:
venv\Scripts\activate

3. Install Dependencies

pip install django pillow

4. Run Migrations

python manage.py makemigrations

python manage.py migrate

5. Create Admin User

python manage.py createsuperuser

6. Start Server

python manage.py runserver

7. Open Browser

http://127.0.0.1:8000
